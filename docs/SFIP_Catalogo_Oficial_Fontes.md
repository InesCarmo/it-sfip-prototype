# Catálogo Oficial de Fontes da SFIP

Este catálogo é a referência oficial da camada de aquisição de dados da SFIP.

Arquivo canónico:
- [`data/sfip-official-source-catalog.json`](../data/sfip-official-source-catalog.json)

Regras de uso:
1. Usar apenas fontes oficiais.
2. Monitorizar a frequência indicada em cada fonte.
3. Confirmar sempre manualmente estado, elegibilidade e prazos quando a fonte não os explicita de forma inequívoca.
4. Tratar cada família de fontes como base para futuras Scheduled Tasks.
5. Expandir o catálogo quando um novo programa, portal ou família de oportunidades for adicionado à SFIP.

Cobertura funcional:
- Programas de Financiamento
- Brokerage & Networking
- Webinars & Info Days
- Radar Estratégico
- Empresas & Ecossistema
- Instituições

Usar este catálogo como fonte única de verdade para:
- aquisição de dados;
- validação de oportunidades;
- segmentação para comunicação;
- radar de novas oportunidades;
- contexto para recomendações.
